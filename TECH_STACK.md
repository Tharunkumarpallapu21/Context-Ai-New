# ContextRoute AI — Technology Stack

- React Native + TypeScript + Expo SDK 57.
- Expo Router for file-based navigation.
- Zustand for local UI state and AsyncStorage-backed persistence.
- React Hook Form + Zod for local form validation.
- React Native Reanimated is retained from the starter for future micro-interactions.
- NativeWind remains available from the fixed starter; the shipped screens use StyleSheet tokens for predictable cross-platform rendering.
- Expo Vector Icons for accessible iconography.
- No Supabase, Firebase, remote auth, cloud database, backend API, remote notifications, cloud storage, or external routing service is connected by the frontend.
