# ContextRoute AI — Design System

## Tokens

- Context Cobalt: `#175CD3`
- Deep Cobalt: `#0B3B91`
- Sky Accent: `#5B9BFF`
- Mist Background: `#F6F8FC`
- White Surface: `#FFFFFF`
- Ink: `#0D1B2A`
- Muted Ink: `#607089`
- Border: `#DCE4F0`
- Success: `#15803D`
- Warning: `#B45309`
- Error: `#B42318`
- Dark Background: `#08111F`
- Dark Surface: `#101C2D`

## Typography

Use platform system sans. Display 30/36 semibold, title 24/30 semibold, section 18/24 semibold, body 16/24 regular, label 13/18 semibold, caption 12/16 regular.

## Shape and spacing

Use an 8-point spacing scale. Cards use 20px radius; hero panels use 28px; pills use 999px. Inputs and buttons maintain a 48px minimum height. Surfaces use a subtle `0 10 30` shadow on web and low-elevation native styling.

## Components

`Screen`, `TopBar`, `PrimaryButton`, `SecondaryButton`, `IconButton`, `SearchField`, `MapPlaceholder`, `BottomNav`, `SectionTitle`, `StatusPill`, `ChoiceCard`, `RouteCard`, `EmptyState`, `NoticeBanner`, `FormField`, `ListRow`, `ModalSheet`, `PermissionCard`, and `AppIcon` are the reusable primitives.

## Accessibility

Every icon-only control has an accessibility label. Touch targets are at least 44–48px. Status meaning uses text and color. Forms use visible labels, helper text, and native keyboard semantics. Bottom navigation has short text labels; no critical action is gesture-only.
